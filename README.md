## 📁 How It Works — Troubleshooting Workflow

1. Install current official ARC Raiders patches before assuming an issue fixed in earlier releases remains unresolved.
2. Record the AMD GPU model, Radeon driver version and Windows build.
3. Temporarily disable ray tracing and compare stability in a repeatable in-game area.
4. Return GPU overclock/undervolt settings to vendor-recommended defaults for the test.
5. Check the game-file integrity and compare performance with an ordinary graphics preset.
6. If crashes persist, collect the error code, relevant logs, driver version and reproduction steps for the developer.
